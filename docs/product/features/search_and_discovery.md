# 검색과 정책 탐색

## 기능 목적

사용자가 기관별 사이트와 서로 다른 용어를 미리 알지 못해도 검색어, 지역,
연령과 관심 분야로 신청 가능성이 있는 청년정책 후보를 찾게 한다. 검색 결과는
자격 판정이 아니라 확인할 정책의 범위를 줄여 주는 탐색 도구다.

## 사용하는 화면

| 화면 | 주소 | 역할 |
| --- | --- | --- |
| 홈 | `/` | 자연어 또는 명시 조건으로 검색 시작 |
| 정책 목록 | `/programs` | 검색 결과·조건 해석·필터·정렬·페이지 이동 |
| 이전 검색 진입 | `/search` | `/programs` 검색 흐름으로 연결하는 호환 route |

## 검색 진입 원리

홈은 두 종류의 입력을 한 요청으로 조합한다.

- 자연어 검색어: 정책명, 대상, 지역, 분야와 일상적인 질문 표현
- 명시 조건: 시·도, 시·군·구, 연령, 분야, 신청 상태

자연어가 비어 있어도 명시 조건이 하나 이상 있으면 검색할 수 있다. 모든 조건이
비어 있으면 무제한 전체 검색으로 바꾸지 않고 입력 검증 오류로 처리한다.

홈 예시 검색어는 실제 공개 dataset에서 결과가 확인된 조건으로 연결된다.
`대학생`처럼 넓은 표현에는 선택 가능한 관련 검색어를 보여줄 수 있지만, 시스템이
사용자 입력을 몰래 다른 대상이나 자격 조건으로 바꾸지는 않는다.

## 자연어 해석 원리

Backend는 원문 검색어를 보존한 채 다음 차원의 조건을 분리한다.

- `region`: 행정구역 이름과 승인된 별칭
- `age`: 문장에서 확인된 만 연령
- `category`: 주거, 고용, 교육, 복지, 금융 등의 분야
- `keyword`: 정책을 특정하는 구체 표현

`청년`, `지원`, `정책`, `사업` 같은 일반어와 질문을 연결하는 표현은 구체
keyword와 구분한다. `월세`, `적금`, `단기숙소`처럼 분야를 암시하면서 정책을
특정하는 표현은 분야 조건과 keyword 발견 근거를 함께 가질 수 있다.

해석 결과는 다음 세 종류로 나뉜다.

| 상태 | 의미 | 화면 처리 |
| --- | --- | --- |
| resolved | 하나의 조건으로 안전하게 해석됨 | 조건과 판정 근거 표시 |
| ambiguous | 둘 이상의 후보가 있어 자동 확정할 수 없음 | 후보 또는 추가 확인 안내 |
| uninterpreted | 현재 규칙으로 의미를 정하지 못함 | 조용히 삭제하지 않고 안내 |

사용자가 form에서 명시한 조건은 같은 차원의 자연어 해석보다 우선한다. 어떤
필드가 명시 입력으로 대체됐는지는 응답의 해석 정보로 추적한다.

## 정책 후보를 찾는 원리

정책의 제목만 찾지 않고 정규화된 검색 projection을 사용한다. projection에는
검색이 허용된 제목, 요약, 분야, 지역, 연령, 신청 상태와 keyword가 포함된다.
Raw HTML·API payload와 관리자 전용 provenance는 일반 검색 대상이 아니다.

구체 keyword가 여러 개면 각 구체 표현이 제목·요약·검색 projection 중 하나에는
일치해야 한다. 일반어만 있는 넓은 탐색은 발견 가능성을 위해 완화된 후보 규칙을
사용한다. 후보를 찾은 뒤에는 지역·연령·분야·상태 판정과 품질 상태를 별도로
평가한다.

## 지역 검색 원리

행정구역은 단순 문자열 포함이 아니라 versioned 기준정보와 정책별 지역 rule로
판정한다.

### 시·군·구를 선택한 경우

- 해당 시·군·구에 직접 적용되는 정책
- 상위 시·도에 적용되는 정책
- 전국 적용 정책

예를 들어 `경상남도 양산시`는 양산시, 경상남도와 전국 정책을 함께 탐색한다.

### 시·도를 선택한 경우

- 해당 시·도에 직접 적용되는 정책
- 그 시·도 아래 시·군·구에 지정된 정책
- 전국 적용 정책

다른 지역으로 확정된 정책은 제외한다. 지역 근거가 없거나 안전하게 해석되지 않은
정책은 전국으로 추정하지 않고 낮은 우선순위의 `지역 일치 미확인` 후보로
구분한다.

관련도가 같으면 선택 지역에 직접 적용되는 좁은 범위 정책을 여러 지역 정책,
전국 정책, 지역 미확정 정책보다 먼저 보여준다.

## 연령·분야·신청 상태

- 연령: 정책의 최소·최대 연령이 모두 확인되면 사용자의 만 연령과 비교한다.
- 분야: 정책은 여러 분야를 가질 수 있으며 하나 이상 일치하면 분야 후보가 된다.
- 신청 상태: 모집 중, 접수 예정, 마감 등 정규화된 상태를 사용한다.

조건이 원문에 없다는 사실과 현재 변환기가 값을 찾지 못한 상태를 구분한다.
확정 불일치는 제외할 수 있지만 근거 부족은 자동 불일치로 바꾸지 않는다.

## 결과 관련도와 정렬

기본 관련도는 keyword 일치와 구조화 조건의 판정 근거를 조합한다. 같은 점수에서는
지역 직접성, 적용 범위, 미확정 조건 수, 신청 상태와 정책 identity 순으로
결정성을 유지한다.

사용자는 다음 정렬을 선택할 수 있다.

- 관련도순
- 제목 가나다·역순
- 마감일 빠른·늦은 순
- 수집일 최신·오래된 순

마감일이 미확정인 정책은 마감일 오름차순과 내림차순 모두에서 확정 날짜 뒤에
둔다. 모든 정렬은 마지막에 안정적인 identity 보조 정렬을 적용한다.

검색 조건, 정렬과 페이지는 URL query에 유지돼 페이지 이동과 상세 진입 후
돌아오기에 사용된다.

## 공개 범위와 품질

검색은 현재 활성 공개 dataset membership에 포함된 정책만 대상으로 한다.
로컬 수집 정책, 이전 개발 데이터와 아직 승격하지 않은 수동 수집 결과는 DB에
있어도 검색되지 않는다.

기본 검색은 `valid`와 공개 가능한 `partial` 정책을 포함한다. `partial`은 일부
정보가 미확정이라는 뜻이며, `invalid`, inactive와 한국 표준시 기준 종료일이
지난 정책은 공개 검색에서 제외한다.

## 프로필과의 관계

저장 프로필은 사용자가 입력한 검색어·지역·연령·분야 필터를 추가하거나 덮지
않는다. 명시 검색 조건으로 후보 집합을 먼저 정한 뒤, 프로필은 관련도와 추천
이유를 보정하는 선호 정보로만 사용된다.

## 빈 결과와 오류

- 조건에 맞는 정책이 없으면 빈 결과 안내와 조건 수정 경로를 제공한다.
- 검색어와 명시 조건이 모두 없으면 유효성 오류다.
- 지원하지 않는 연령, 분야, 상태, 정렬 값은 `422`로 거부한다.
- 서버·네트워크 오류는 빈 결과와 구분하고 재시도 가능한 상태로 안내한다.
- 페이지·limit이 현재 요청과 다른 늦은 응답은 화면의 최신 결과로 채택하지 않는다.

## 현재 제한사항

- 의미 기반 생성형 검색이 아니라 설명 가능한 규칙과 정규화 projection을 쓴다.
- 기관의 최신 공고 변경이 새 공개 dataset 승격 전까지 즉시 반영되지는 않는다.
- 지역·연령·분야가 미확정인 정책은 완전한 자격 필터링을 보장하지 않는다.
- 검색 결과만으로 신청 가능 여부를 확정할 수 없다.
