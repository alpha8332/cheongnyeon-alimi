# 거버넌스 문서

이 디렉터리는 공개 저장소의 기여와 릴리스에 적용되는 공통 규칙을 관리한다.

- [브랜치 전략](branch_strategy.md): `main`, `develop`, 작업 브랜치와 릴리스 흐름
- [커밋 작성 규칙](commit_convention.md): Conventional Commits
- [코드 리뷰 정책](code_review.md): PR 검토, 테스트와 병합 기준
- [문서화 정책](documentation_policy.md): 현재 계약과 검증 결과의 유지 기준
- [역할과 책임](role_assignment.md): Data·Backend·Frontend·Integration·QA 경계

예정 작업은 GitHub Issue와 Pull Request에서 관리한다. 저장소 문서는 현재
사용자 기능, 시스템 계약, 운영 방법과 재사용 가능한 문제 해결 기록을
설명하는 데 집중한다.
