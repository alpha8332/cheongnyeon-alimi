# Release 1 경량 리뷰 근거 요약

## 근거와 판정 범위

- 검토 일시: `2026-08-06T13:31:38+09:00`
- 원본: Team Leader가 제공한 `v0.1.0 리뷰.docx`
- 검토 방식: 기본 Web UI QA와 사용성 확인
- 판정 범위: `v0.1.0` 실제 정책 검색 MVP의 기본 기능

원본 Word 문서의 본문과 포함된 화면 3개를 확인해 저장소에 비밀정보나 개인
정보 없이 관찰 결과만 요약했다. Team Leader는 Release 1을 기본 기능 확인
범위로 마감하고, 독립성 확인과 보고서 대조를 필수 Gate에서 제외해
`v0.5.0`으로 이관했다. exact golden query·snapshot·contract·응답시간은 수동
리뷰가 아니라 자동 기술 증거로 검증한다.

## QA 관찰

### 기본 검색과 상세

- 검색 결과와 정책 상세의 기본 흐름이 표시됐다.
- 상세 화면에서 기관, 데이터 출처, KST 수집 시각, 지역, 연령, 카테고리,
  지원 내용과 자격 비확정 안내를 확인했다.
- Source에 자격 요건·신청 방법·신청 기간이 없으면 `정보 없음` 또는 `미정`으로
  표시됐다. 이를 임의로 채우지 않는 현재 동작은 안전하지만 데이터 보강은
  4주차 후속으로 분류했다.

### 빈 결과

- 미일치 검색에서 빈 결과 설명, 입력 검색어, 해석된 연령과 미해석 키워드가
  유지됐다.
- 리뷰 화면에서 발견한 `canonical Seed 기반` 문구는 실제 Release snapshot
  계약과 달라 `고정된 실제 정책 snapshot 기반` 안내로 수정했다.
- 더 넓은 Source 수집과 문구 개선은 `v0.5.0` 후속으로 분류했다.

### partial·unknown 경계

- 정보 일부 누락과 자격 확인 필요 표현이 구분돼 표시됐다.
- 검색 결과가 실제 자격 충족을 확정하지 않는다는 안내가 노출됐다.

## 사용성 관찰

- 해석된 연령 조건과 미해석 키워드를 화면에서 확인할 수 있었다.
- 선택한 정책과 조건 판정 결과가 표시됐다.
- 출처와 수집 시각이 표시됐고, 후보 안내가 실제 자격 확정이 아니라는 경고가
  확인됐다.
- 지역 목록이 긴 정책은 카드 높이가 과도해지는 문제가 있다. 지역 일부만
  표시하고 나머지를 축약하는 개선을 4주차 후속으로 분류했다.

## 비차단 후속사항

- Source에 없는 자격·신청 정보의 추가 수집 또는 보강 경계 검토
- 긴 지역 목록 축약 UI
- API 오류를 3~5초 토스트와 닫기 버튼으로 표시하는 UX
- `v0.5.0` 기능·사용성 검증과 함께 보고서 근거 작성 시작

API 오류·재시도 흐름과 보고서 근거 대조는 이번 리뷰에서 실제 수행하지
않았으므로 통과로 기록하지 않는다.
